## 1. 建议编号与标题

- **标题**：VL 基在 NumBasis 1–4（n_G=1）时，图案层流场的 1×1 网格使零场被静默归一化为 NaN 并返回成功，导致特征值求解以 info=2 失败
- **建议状态**：未确认生产缺陷（实现/targeted/阶段验收/生产关闭四项均未开始，见第 7 节）

## 2. 症状（可观察，[实测]）

| 项 | 观察 |
|---|---|
| 触发 | VL 基（`PolarizationBasis="Default"`，ClosedForm + PolBasisVL，默认选项）、NumBasis 1–4（n_G=1）、图案层存在 |

## 3. 机理（[实测] 与 [源码]）

1. `fmm_PolBasisVL.cpp:98–112` 的 `allzero` 分支：当所有 G 分量为零（n_G=1，G={(0,0)}）时，流场网格强制为 **1×1**，并跳过分辨率缩放（[源码]；[实测] `ngrid={1,1}`）。
2. 1×1 网格上，圆的穿越边给出贡献 `+1,+1,−1,−1`，相互抵消，右端项 `b={0,0}`（[实测] 条件断点；与独立几何计算的符号一致）。
3. 解得 `x={0,0}`，场 `max_field = 0`（[实测] `pattern.c:2145`）。
4. `pattern.c:2145–2149`：`max_field = 1./max_field`，场乘以该值。得 `inf × 0 = NaN`（[实测] `vfield = -nan`）。
5. `pattern_generate_flow_field` 在归一化之后**无检查**，返回 0（`pattern.c:2146–2152`，[源码]）。
6. NaN 进入 `Epsilon_inv`、`Epsilon2`（[实测]），特征值求解返回 info=2，`ComputeLayerModes` 返回 20（`S4.cpp:2356–2362`，[源码]）。

**对照**：Jones 与 NV 无 `allzero` 分支，同一 NG=1 下网格为 8×8，`max_field=0.0402`，不产生零场（[实测]）。FFT 路径有相同的 `allzero` 约定（`fmm_FFT.cpp:55–60`），但不调用流场归一化器（经 `Pattern_DiscretizeCell` 构造，[源码]），故不受同一步骤影响。

**反事实**（仅改 `allzero` 分支，`cf/` 草稿，`S4/` 未改）：VL NB 1–4 由失败变为成功，通量 0.95890；NB 5–9 不变（约 1e-13）。该反事实的**正确性未经独立参考验证**（第 6 节开放项 1）。

## 4. 为什么这是 D003 之外的独立缺陷（建议理由）

- 该失败是**显式报告**的（异常、info=2），不是 D003 所定义的"静默错误数值"（公共 API 的 27 个 OK 结果均为有限值，[实测]）。因此不并入 D003 的危险模式。
- 但根因步骤（`1./max_field` 后无检查）是**静默**的，且把合法输入（一个圆穿越 1×1 单元）误判为求解失败，报告的原因（特征值）与真实原因（流场归一化）不一致。这是独立的缺陷，应单独跟踪。
- S3 的既有决定"O-1 不并入 D003"（`S3_OPEN_ITEMS_AND_SCOPE_FREEZE.md:171`）与此一致；本草稿把它登记为**独立缺陷**，而不是 D003 的一部分。

## 5. 与既有记录的关系（必须区分，不得合并）

- **`testing/s4test/DEFECTS.md` 约 1187–1195 行（"1×1 图案采样"发现）**：同样涉及"1×1 网格 + 图案层"，但机理不同。该记录是**一点 FFT 网格只能表示零阶 Fourier 项**，导致内部网格路径与点场路径不一致（`|1x1 grid − point field| = 2.21`）。本草稿的机理是**零场被归一化为 NaN**。两者都与 1×1 网格有关，但不是同一缺陷。登记时应互相引用，并在各自条目中写明不同机理。
- **R-P04-xx 系列**：本草稿与 R-P04 无重复（R-P04 涉及短工作区越界、query 防御路径等）。
- **D001–D015**：无同症状条目（[实测] 检索）。

## 6. 开放项（决定能否从"未确认"升级）

1. **反事实通量的正确性**：NB=1 的透射通量 Jones 0.97136、Normal 0.97441、VL 反事实 0.95890。三者是不同公式化，1–2% 差异不证明任何一方正确。在缺少独立参考（例如 NG=1 的收敛序列外推或解析参考）前，不能声称"修复后结果正确"。
2. **`allzero` 分支的设计意图**：源码无注释，历史仅见 `c0a8e69`。若设计上有意保留 1×1 网格，则缺陷在于归一化对零场的处理，而非网格本身。该区分决定修复的位置。
