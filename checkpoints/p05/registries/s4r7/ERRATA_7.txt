== E7-10 gdb chain method (section 5)
'finish' stops the program at the first return of each breakpoint, so a finish-based run never reaches the injection path
beyond the first breakpoint (observed in the first two jones attempts: only Simulation_ComputeLayerModes printed, rc 0).
The judged chain therefore uses a continue-only run (gdb_chain_jones_entry_r7.gdb), and return values are read in a separate
finish run (gdb_chain_jones_finish_r7.gdb).  Consequence: for every chain run, FMMGetEpsilon_PolBasisJones' RETURN VALUE is 未读到
(its finish breakpoint is never reached in the finish run).  Recorded in GDB_CHAIN_SUMMARY_R7.tsv; not filled from source.

== E7-32 S4FMM_NTH missing from the M2b environment; run5 G1 and G2c are HARNESS_INVALID (U69)
What happened.  run5 (run_m2b_all_r7.py run) built the environment of each point as FMM_MODE, S4FMM_NG, S4FMM_INJECT and
(twice) S4FMM_TWICE, but never S4FMM_NTH.  The injector then defaults to the first call (inject_d003.cpp:38).  Every point
with nth > 1 therefore injected at the first call, not at its own nth.
Historical environment.  matrix_r2.build_env(row) (matrix_r2.py:98-109) sets S4FMM_NTH = row["nth"] whenever nth is not "-" or
empty, and S4FMM_TWICE = slab only when case starts with "t4/".  The historical runners set these fields as follows:
  G1  run_r3_sweep.py:117-118   case = ("t4/" if route == "twice" else "r3/") + point_id; nth = the NTH of the point id.
  G2c run_r4_regress.py:79-81   the same case rule (t4/ or r3/ by route); nth = str(nth) of RESULTS_R3.
  G2a run_r4_matrix.py:101-102  nth = "-"; case = point_id; no S4FMM_NTH and no S4FMM_TWICE.  Stated, not inferred.
Consequence (void results, not counted in M2).
  G1 (run5): 94 MISMATCH rows (22 INVALID_NOT_REACHED points with hit 1; twice, inj_call 2 points with rc1 20 and rc2 0 judged
  SILENT_SWALLOW), 204 MATCH rows.  G2c (run5): 60 MATCH rows.  All of these used the first-call injection and are void.
  CTRL_SEAM (run5): 4/4 CONTROL_OK, both passes; no injection, so NTH is not relevant; kept.
  Not affected: M1 (request rnv1:M), M2a (request plancall:K:M, its own environment), G2a (its request carries its own index).
Classification.  Not ENV_DRIFT and not REGRESSION.  HARNESS_INVALID (U69).
