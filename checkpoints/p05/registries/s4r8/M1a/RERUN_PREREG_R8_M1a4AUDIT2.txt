# 2. Design of the new tracer and runner (described; not written as code in this round)
DESIGN_TRACER	(a) every out_of_scope callback appends a record TRACE_OUT_OF_SCOPE (type, seq, plan or window) to EVENTS and sets SUMMARY trace_error; the unit then fails T1.  (b) On every FinishBreakpoint creation, a record TRACE_FINISH_OK is written at the stop; a unit without one for each opened plan/window fails.  (c) Breakpoint location and pending state are read after creation and written to SUMMARY (addr, pending, locations); a required symbol with pending or zero locations is REQUIRED_SYMBOL_MISSING; a non-required symbol is recorded, not raised.  (d) Entry-address check: the breakpoint address must equal the ELF st_value of the symbol (readelf); otherwise TRACE_ERROR.  (e) Parameter source: DWARF variable first; when absent, the x86_64 $rdi value at function entry is used and the source is recorded as REG_FALLBACK per hit.
DESIGN_RUNNER	(a) the runner reads the unit table, checks driver sha256 and argv, and sets the environment from the unit row only (env -i plus the registered variables); (b) a unit passes only if gdb rc is 0, SUMMARY status is EXITED, exit_code is recorded, trace_error is null, and no TRACE_OUT_OF_SCOPE or TRACE_ERROR record is present; (c) each unit's raw log is saved under a new directory callseq_r8m1a4_rerun/<unit>; (d) the runner refuses to overwrite a directory (U17).
DESIGN_NO_HISTORY_CHANGE	No file of the historical tracer (callseq_r8m1a4_gdb.py, callseq_runner_r8m1a4.py) is modified.  The new tracer and runner are new files with the rerun round name.
