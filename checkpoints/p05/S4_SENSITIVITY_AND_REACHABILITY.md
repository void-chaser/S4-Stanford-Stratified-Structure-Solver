**三层机制（全部由运行证实）**

2. **`kp` 与 `Epsilon_inv` 无关**：一般分支先把 `Epsilon_inv` 复制进 `kp`（`rcwa.cpp:299–302`），再对各块乘以 `-ky`、`kx`、`ky`、`-kx`（`:37–47` 的 `Scale`）。`kx=ky=0` 时块全为零，只剩 `ω²` 对角（`:48–51`）。实测 `kp=(39.3995, 0, 0, 39.3995)`，改值前后相同。

## 3. C 的结论更新

### 3.1 结论

**C 保持开放。** 本轮没有关闭它，但改变了它的证据状态：

- **T12 对 C 的证据被削弱**：T12 的"输出未变"发生在 NB=1 正入射，那是 `Epsilon_inv` 结构上不能传播的配置（T16）。因此 T12 不能作为"中间量错误不传播"的一般证据。
- **C 的真正检验需要**：`kx` 或 `ky` 非零的配置。在这种配置下 `Epsilon_inv` 会进入 `kp` 与 `ney`，传播可能发生。本轮未测。

### 3.3 T16 与 T17 的交汇

B 的窗口内分配可达的 NB（1–4）与 `kx=ky=0`（T16 的不传播条件）**覆盖的是同一组配置**：

- 在 NB=1–4 上：中间量错误可达（T12），但 `kx=ky=0`，所以它不通过 `kp` 与 `ney` 传播到输出（T16）。
- 在 NB≥5 上：B 不可达（T17）。
- **因此在当前几何与正入射下，B 的输出层面伤害不可达。** 这是结构性结论，由几何决定，不是某次运行的偶然结果。

**边界（不能外推）**：这一交汇只对正入射成立。斜入射时 `S->k[0]`、`S->k[1]` 非零，`kx`、`ky` 非零，`Epsilon_inv` 会进入 `kp` 与 `ney`，B 的中间量错误可能传播到输出。**本轮未测斜入射。** 这正是 C 保持开放的原因。

### 3.4 对 S3 的修正

S3 报告（第 4 节 B 与第 6 节）只写了"中间量 `Epsilon_inv` 错误，求解失败未被上报"，**没有写出传播路径**。但 S3 的 D003 表隐含了"中间量错误会经特征值问题影响结果"这一假设，因为它把"中间量错误"当作纳入 B 的理由。T16 的 `kp` 观测（改值前后 `kp` 相同）是对这一隐含假设的**反例**，适用于 NB=1 正入射：中间量错误不通过 `kp` 影响特征值问题。S3 中 "`Epsilon_inv` 永久错误" 的叙述仍然成立（实测），但它的传播路径应当写为：`Epsilon_inv` → `GetFieldOnGrid`（经 `ney` 与 `eh[n..]`），而对 NB=1 正入射，这条路径也因 `ney=0` 而不传播。第 6 节第 1 条列出。（注：本节初稿曾把这一假设写成 S3 的显式陈述，那是转述错误，已在此更正。）

**建议**：B 的危险等级定为 **"条件可达，输出层面未观察到伤害"**。

- "条件可达"的条件是：`fft_plan_exec` 内的 `kf_bfly_generic` 分配失败，且该分配发生在 1×1 网格（NB=1–4）。
- **需要区分的两个现象**：B 的窗口内分配（`kf_bfly_generic`，16 字节，T17）与 O-1 的 VL 特征值失败（`info=2`，T18）是**两个不同的现象**。它们恰好覆盖同一组 NB（1–4），但本报告**没有**建立它们之间的因果关系：B 的判定只依据 T17 的窗口内计数，O-1 的判定只依据 T18 的 `n_G`，两者互不依赖。
- "输出层面未观察到伤害"的依据是：T16 的 NB=1 正入射结果，以及它的结构性解释（`kx=ky=0`）。
- **不建议**把 B 升为"输出错误"，因为没有任何可达配置上观测到输出错误。
